# storyboard — 视频分镜

案板创作流程的最后创作环节：**把"说的"变成"看的"**。口播稿是骨，分镜是肉。

## 什么时候用

- 口播稿定稿，要进入拍摄/剪辑阶段
- 用户说"帮我排个分镜""这段配什么画面"
- 需要估算素材量（要拍多少 B-roll、找多少资料画面）

## 流程

### 1. 按语义切段

把口播稿按**叙事单元**切段（不是按句切）：每段 = 一个完整意思。通常 3-5 分钟的稿子切成 8-15 段。给每段起小标题（钩子/背景/事件1/事件2/反转/金句…）。

### 2. 逐段配画面

对每段决定画面类型：

| 类型 | 适用 | 例子 |
|---|---|---|
| 实拍 | 美食制作、食材特写 | 切菜、下锅、出锅 |
| 资料画面 | 历史/博物叙述 | 老照片、地图、史料扫描 |
| 动画/图示 | 抽象概念、数据 | 传播路线图、时间轴 |
| 口播直出 | 情绪点、金句 | 结尾金句怼脸拍 |

每段至少 1 个主画面 + 1 个备选。**注意：历史/博物内容没有实拍素材，资料画面要提前找好，别到剪辑时才抓瞎。**

### 3. 标字幕与音效

- 字幕 = 口播稿原文分段，标注**卡点**（哪句配哪个画面）
- 音效：转场音、锅气音、环境音（菜市场/厨房），金句处可加"顿一下"
- 音乐建议：BGM 风格 + 换段点

### 4. 控制节奏

- 每段时长 = 口播字数 ÷ 250 字/分钟
- 3 分钟视频：前 15 秒必须出现"钩子画面"，别用 30 秒片头
- 长段（>30 秒）必须切画面，否则观众流失

## 输出格式

```markdown
# 分镜脚本：<标题>（时长约 X 分钟）
| 镜号 | 时间 | 画面 | 口播（字幕） | 音效/BGM |
|---|---|---|---|---|
| 1 | 00:00-00:08 | 钩子画面：… | 「…」 | 音效+音乐起 |
| … | | | | |

## 素材清单
- [ ] 实拍：…（地点/镜头）
- [ ] 资料画面：…（来源/链接）
- [ ] 音乐：…
```

## 坑（血的教训）

- **别把分镜写成"念稿 PPT"**：画面和口播要互证，不是把文字打在屏幕上
- **历史向别硬拍**：没有实拍素材的段落，提前规划资料画面/图示，别留白
- **别忽略转场**：段与段之间要有钩子（"但事情没这么简单…"），分镜里要标出来
- **字幕别整句糊上去**：按节奏断行，一行 ≤ 12 字

## 验证

- [ ] 口播稿每段都有对应画面（无"留白"段）
- [ ] 镜号/时间轴完整，总时长与稿子吻合
- [ ] 素材清单可执行（资料画面有来源，实拍有地点）
- [ ] 前 15 秒有钩子画面
