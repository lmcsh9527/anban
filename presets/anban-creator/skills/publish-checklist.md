# publish-checklist — 发布清单

案板流程的最后一公里：**别让好内容死在发布环节**。B站/YouTube 双平台的规则不同，一次列全，逐项打勾。

## 什么时候用

- 视频剪辑完成，准备上传
- 用户说"帮我写简介""起个标题""发布前检查"
- 发布后要复盘数据

## 流程

### 1. 标题

- **B站**：可长可具体，爆点前置；主标题 ≤ 30 字，可带副标题（"｜"分隔）
- **YouTube**：关键词前置（SEO），≤ 60 字符（英文更宽）；风格统一
- 两平台可不同标题，别偷懒复制

### 2. 封面

- 主视觉 + ≤ 6 字卖点文字（大字）
- 手机缩略图尺寸下可读（小屏测试）
- 别用误导性封面（违反平台规则且掉信任）

### 3. 简介与标签

- B站：简介写 1-2 句内容预告 + 时间戳目录 + 资料来源/参考文献（**事实核查清单放这里**，被质疑时直接有据）
- B站标签：5-10 个，含领域词+具体词（"美食#历史#鳕鱼战争"）
- YouTube：description 前 2 行放关键词；tags 3-5 个主词；加时间戳（chapters）

### 4. 发布设置

| 项 | B站 | YouTube |
|---|---|---|
| 分区 | 生活/美食/知识 | 按类目 |
| 定时发布 | 晚间 18-22 点高峰 | 依受众时区 |
| 互动 | 置顶评论提问 + 投票 | pinned comment + 提问 |
| 合集 | 归入母链合集 | playlist 归入系列 |

### 5. 发布后 24-48h 复盘

- 看数据：完播率（重点）、点击率、弹幕/评论热词
- 找"流失点"：哪段完播骤降 → 记下来，下一期分镜避坑
- 回评论：前 24 小时积极回复（权重最高）
- 记录到母链档案：这期验证了哪个选题角度？哪些角度失败？

## 输出格式

```markdown
# 发布检查：<标题>
## 发布前
- [ ] 标题：B站「…」/ YouTube「…」
- [ ] 封面：主视觉+卖点（小屏可读）
- [ ] 简介：预告+时间戳+资料来源
- [ ] 标签/关键词：…
- [ ] 分区/合集/定时：…
## 发布后（48h 内回填）
- [ ] 数据：完播 X%、点击 X%
- [ ] 流失点：…
- [ ] 评论回复：完成
- [ ] 母链档案更新：…
```

## 坑（血的教训）

- **别一个标题走天下**：两平台受众和搜索逻辑不同，分平台优化
- **别漏资料来源**：历史/博物内容简介里必须给来源，既防争议也涨信任
- **别错过黄金 24h**：发布后前 24 小时的互动权重最高，别晾着
- **别只发不复盘**：不复盘 = 每一期都是第一期

## 验证

- [ ] 双平台标题/封面/简介都单独优化过
- [ ] 简介含事实来源（fact-check 的产物）
- [ ] 归入母链合集/playlist
- [ ] 48h 内完成数据复盘并回填清单
